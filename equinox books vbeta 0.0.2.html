Descripción y Arquitectura Interna del Sistema

Equinox-Books es un sistema de gestión contable y auditoría fiscal diseñado para ofrecer una experiencia visualmente limpia, robusta y de alta precisión para medianas y grandes empresas. Inspirado en la simetría del equinoccio, la plataforma garantiza el equilibrio absoluto entre activos y pasivos, centralizando los flujos financieros de manera eficiente y automatizada.

Stack Tecnológico Implementado (Modo Navegador Offline)

  • Frontend: HTML5, CSS3 con variables corporativas, JavaScript ES6+.
  • Motor de Lógica: JavaScript nativo (aritmética entera de centavos, Cero Float).
  • Base de Datos: localStorage del navegador (persistencia local real, equivalente a SQLite local; migrable a PostgreSQL/MySQL vía API REST).

Reglas de Diseño y Controles Internos

  • Inmutabilidad del Libro Diario: el libro diario sólo escribe (append-only); nunca edita ni borra registros directos.
  • Cero Float: toda moneda se convierte a enteros en centavos mediante análisis de cadena, eliminando errores de punto flotante IEEE 754.
  • Corrección mediante Reversión: los errores se corrigen con un asiento reverso automático que preserva la trazabilidad de auditoría.
  • Validación de Partida Doble: ningún asiento se registra si Débito ≠ Crédito.
  • Modelo de Cuentas Jerárquico: control estricto por tercero e indicadores para auditoría fiscal en tiempo real.
